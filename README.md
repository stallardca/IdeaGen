# Idea Evolution Tree

This is a single-page HTML app. Run a small local web server from the repo root and open the page in your browser.

## Quick start

```bash
cd /workspace/IdeaGen
python -m http.server 8000
```

Then visit:

```
http://localhost:8000/index.html
```

If you see “Not Found”, double-check that you started the server in the same folder that contains `index.html`.
